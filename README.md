# Django Polling Application

## 📌 Project Description
The Django Polling Application is a web-based application that allows users to participate in polls and vote for their preferred options. It provides a simple and user-friendly interface for creating polls, viewing available questions, and submitting votes.

This project is developed using Python and Django, with a database to store poll questions, choices, and voting results.

## 🚀 Technologies Used
- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite Database
- Git & GitHub

## ✨ Features
- User-friendly interface
- View available poll questions
- Vote for preferred choices
- Store voting details in the database
- Display voting results
- Dynamic web pages using Django templates

## ⚙️ Installation and Setup

### 1. Clone the repository
```bash
git clone https://github.com/jeeshasathish/Polling.git
```

### 2. Navigate to the project folder
```bash
cd Polling
```

### 3. Create a virtual environment
```bash
python -m venv venv
```

### 4. Activate the virtual environment

Windows:
```bash
venv\Scripts\activate
```

### 5. Install dependencies
```bash
pip install django
```

If a `requirements.txt` file is available, use:
```bash
pip install -r requirements.txt
```

### 6. Apply database migrations
```bash
python manage.py migrate
```

### 7. Run the development server
```bash
python manage.py runserver
```

### 8. Open in browser
```text
http://127.0.0.1:8000/
```
